# 01. 协议实现规格 —— LocalSend 兼容接口（实施照此编码）

> 状态：已由 `localsend/main` 源码钉死（packages/core，Rust，协议 2.2，Apache-2.0）。
> 参考版本：main 分支 @2026-10-16，`packages/core/src/{multicast,discovery,http,model}/*`。
> 标注 ⚠️ 的为**应用层策略**（协议 SDK 不强制），可自行定义。

## 1. 设备发现（UDP 组播）

- [x] 组播地址 IPv4：`224.0.0.167`（特意选在 224.0.0.0/24 内，老 Android 也能收）
- [x] IPv6 组播：`ff12::fd3a:e420`（临时组，link-local scope；可实现于不实现）
- [x] 端口：`53317`（与 HTTP 同端口）
- [x] **载荷 = JSON**（不是 HTTP 文本！）：
  ```json
  {"alias":"PC-1","version":"2.2","deviceModel":"Windows","deviceType":"desktop",
   "fingerprint":"<随机串|证书SHA-256>","port":53317,"protocol":"http","download":true,
   "announce":true}
  ```
  - `deviceType`：`mobile|desktop|web|headless|server`，未知值回退 `desktop`
  - `protocol`：小写 `http`/`https`；`download`：下载 API 是否开放
  - `announce:true` 为 v2 兼容遗留字段（发送时才带）
  - HTTP 模式 fingerprint = 随机持久串；HTTPS 模式 = 证书 SHA-256 大写十六进制
- [x] 发送节奏：三次连发 @100ms / 500ms / 2000ms（单包易丢，新人刚入网没准备好）
- [x] **UDP 只发不回**：收到者用 **HTTP `POST /api/localsend/v2/register`** 单播回执
- [x] 丢弃自己发出的报文（fingerprint 相同）
- [x] register 请求超时：`500ms`（默认）
- [x] 去重键：`fingerprint`（含 IPv4/IPv6 双栈场景）
- ⚠️ 广播周期 / 离线超时：SDK 留给应用层（推荐 10s 一轮 announce，2 轮未回应标离线）

## 2. HTTP API（本机 TCP `0.0.0.0:53317`）

| 方法 | 路径 | 请求体 | 响应 |
| --- | --- | --- | --- |
| GET | `/` | — | 浏览器下载页 HTML（Web 分享） |
| GET | `/i18n.json` | — | 下载页 i18n 文案 |
| POST | `/api/localsend/v2/register` | JSON `RegisterDtoV2` | 200 JSON `RegisterResponseDtoV2` |
| GET | `/api/localsend/v2/info`（v1.17 旧客户端探 `v1/info` 亦可） | — | 200 JSON `InfoResponseDtoV2` |
| POST | `/api/localsend/v2/prepare-upload` | JSON `{info, files}` | 200 `{sessionId, files:{fileId:token}}` / 204 / 403 / 409 |
| POST | `/api/localsend/v2/upload?sessionId=&fileId=&token=` | **裸文件字节流** | 200 空体 / 403 / 422 / 500 |
| POST | `/api/localsend/v2/cancel[?sessionId=]` | — | 200 空体 |
| POST | `/api/localsend/v2/show` | — | 内部端点（忽略） |
| POST | `/api/localsend/v2/prepare-download` | JSON | 200 `{info, sessionId, files}`（Web 分享会话） |
| GET | `/api/localsend/v2/download?sessionId=&fileId=&pin=` | — | 200 文件流 → 浏览器下载 |
| POST | `/api/localsend/v3/nonce` `/register` | JSON | v3 扩展（先用 nonce+令牌签名；可实现于不实现） |

### DTO（camelCase）
- `RegisterDtoV2` = `{alias, version, deviceModel?, deviceType?, fingerprint, port, protocol, download}`
- `RegisterResponseDtoV2` / `InfoResponseDtoV2` = `{alias, version, deviceModel?, deviceType?, fingerprint, download}`
- `PrepareUploadRequestDtoV2` = `{info: RegisterDtoV2, files: {fileId: FileDto}}`
- `PrepareUploadResponseDtoV2` = `{sessionId, files: {fileId: token}}`
- `FileDto` = `{id, fileName, size, fileType, sha256?, preview?, metadata?{modified?, accessed?}}`
  - 时间戳 RFC3339（可带小数）；`modified/accessed` 用于对端还原文件时间
- `fileType`：MIME；文本/剪贴板发送 = 虚拟文本文件（`text/plain`，fileName 自定）

## 3. 发送流程（本机→对端）

1. `POST …/prepare-upload`（info = 自己的设备信息 + files）
   → 对端弹确认；**接受**：200 含 sessionId + 每文件 token；**拒绝**：403；**忙碌（仅单会话槽）**：409
2. 对每个接受的文件：`POST …/upload?sessionId&fileId&token`，body = 文件原始字节（流式，512KB 块）
3. 全部完成或出错即收尾；上传失败对端返回 422（sha256 校验失败）或 403（token/IP 不符）
4. 可任意时刻 `POST …/cancel[?sessionId]`（取消待确认/进行中）

**服务端会话规则（照抄实现）**
- 同时只允许 **1 个 upload 会话**（多出 409 "Blocked by another session"）
- 会话绑定 `sender_ip`（IP 变 = 403）；每文件独立 token（uuid4）；文件状态 Pending→InProgress→Finished/Failed
- 空文件集请求 = 400；未接受任何文件 = 204
- 待确认期间发送端断开/cancel → 会话槽释放（PendingSessionGuard）

## 4. 接收流程（对端→本机）

1. 收 `prepare-upload` → 弹确认（别名 + 文件清单：文件名/大小/类型/总数）
2. 用户接受（可只接受子集）/拒绝；自动保存开关命中时直接全收
3. 每文件流式落盘（目标目录 = 快速保存目录或用户确认）；比较 `size`，`sha256` 可验（422）
4. 会话内所有文件终态后发 `SessionEnd`；校验文件数 = 声明数
- ⚠️ 信任列表判定：按 `fingerprint`（+收藏/自动保存名单）——应用层策略
- ⚠️ 落盘校验：文件数 + 总大小与 `files` 声明一致

## 5. 取消 / 状态

- [x] `…/cancel` 无 sessionId 时按发送者 IP 取消**待确认**会话；有则取消 active 会话
- [x] 对未知会话的 cancel：对端会把 `CancelReceived{ip, sessionId}` 通知本地 → **本地据此取消正在发送给对方的那条**（双向）
- ⚠️ 会话过期：SDK 无自动过期（靠 cancel/断连/完成回收）；应用层可加闲置超时

## 6. 传输安全

- HTTP 模式：无认证（靠确认框），fingerprint 仅用于身份标记
- HTTPS 模式（可实现于不实现，二期选项）：
  - 本机自签证书；**mTLS 双向**：register 的 fingerprint 必须等于对端客户端证书 SHA-256（防伪造）
  - 客户端把对端证书指纹 pin 到已收录设备（账号式固定），首次连接提示校验
- 上传大小/总数上限：应用层可设（防撑爆磁盘）

## 7. Web 链接分享（S4 专用，天然本地）

- 发件人 `POST …/prepare-download`（files 声明）→ 局域网内任何人浏览器打开 `http://<IP>:53317/`
  → 页面列出文件 → `GET …/download?sessionId&fileId` 逐个下载（可加 `pin` 4~N 位查询参数防护）
- **纯本机服务，零中继**（LocalSend 官方也是本地 HTTP 直出，云端 WebSocket 仅用于跨网）
