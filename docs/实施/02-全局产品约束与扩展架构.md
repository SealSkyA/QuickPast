# 02. 全局产品约束与扩展架构

> 用户定稿的桌面端全局要求（2026-10-16），实施各阶段必须满足；
> 与《01-协议实现规格》同为编码依据。

---

## 1. 自定义安装位置 + 安装器符合 UI 规范

- 安装包：Tauri 自带 bundler + NSIS（S6 打包实现）。
- 安装时可**选择安装目录**（NSIS 默认提供目录选择页，`installMode: both` 支持按用户/按机器）。
- 安装器界面要用**新拟物视觉**：通过自定义 `custom.nsi`（Modern UI2 + 自定义皮肤/配色变量
  `--bg/--lt/--sh/--acc` 同款，圆角、无硬边框、平铺图标背景），S6 时以 NSIS 编译期脚本做到。
- 卸载时保留数据（缓存/历史库在 `%APPDATA%`，不因卸载清除）。

## 2. 常见分辨率适配

- 主窗口：默认 **980×720**，最小 **820×600**（可拖放缩放到 4K/1080p/720p 均可看全）。
- UI 布局：内容区已 `max-width` + 弹性布局；发送/接收/历史列表纵向滚动，窄屏不挤出。
- 高分屏：Tauri 默认按 DPI-aware（`with-zoom` 待评估），字体用逻辑 px 即可。

## 3. 窗口尺寸/位置记忆

- **几何记忆**：移动/缩放事件(去抖 900ms)写入 `settings.json` 的 `window.geometry`；
  下次启动在创建窗口后**恢复到上次位置尺寸**；若目标位置已不在任何显示器上则自动居中。
- 运行期拖动 = 无边框窗口自带拖拽区（`.titlebar` 挂 `data-tauri-drag-region`）。
- 置顶状态也持久化（`pin` 键），切到「文件传输」自动置顶、返回「快捷粘贴」默认还原（按需求）。

## 4. 扩展能力（预留）

### 4.1 在线更新（预留）
- `tauri-plugin-updater` 在 Cargo 依赖清单中保留（feature-gated，默认不启用体积）；
- 发布配置预留：`updater.endpoints` + 公钥占位；离线内网环境中，更新走"管理员下发安装包"手动路径，代码留好接口。

### 4.2 可插拔模块（如未来「截屏工具」）
- 后端：`src/modules/` 目录 + 统一 `Module` trait（`name/tray_items/commands`）。新工具 = 新增一个 crate/模块，向托盘菜单与主界面「工具」区注册自己。
- 前端：主界面左侧 rail 允许模块注入（原型里 rail 由 `pages` 配置驱动），新工具加一行配置即可。
- IPC 命名空间：`qp.*`（`qp:open-about` 等），避免与核心命令冲突。
- 占位实现：`src/modules/mod.rs` 提供注册表与空实现，保证骨架期就有扩展点。

### 4.3 升级/扩展安全边界
- 模块命令一律走 Tauri capability 权限声明，默认最小权限。
